# Lidiya Aramde — Personal Portfolio

🌐 **Live Demo:** [https://lidiyaa-portfolio.vercel.app/](https://lidiyaa-portfolio.vercel.app/)

Personal developer portfolio for **Lidiya Aramde**, Computer Science student at Addis Ababa University. Built with React, TypeScript, and Vite.

## 🚀 Live Demo

Check out the live website at: **[lidiyaa-portfolio.vercel.app](https://lidiyaa-portfolio.vercel.app/)**

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Vanilla CSS (Custom Design System, Dark Mode)
- **Deployment**: [Vercel](https://lidiyaa-portfolio.vercel.app/)

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 📝 Updating Content

All portfolio content (projects, experience, skills, and links) is stored in one file:
👉 **`src/data/portfolioData.ts`**

Edit that file to add new projects, update links, or change your bio.
